# System Documentation (SD) — Guidelines

These guidelines are split from `system-design/SystemDocumentationTemplate-SRS-SDD-STD-v4-7April2022.doc.md`. The SD is a single document that combines three standards:

- **SRS** — Software Requirements Specification (Chapter 2)
- **SDD** — Software Design Description (Chapters 3, 4, 5, 6)
- **STD** — Software Test Documentation (Chapter 8 + Appendix A)

The title page details (title, version, date, etc.) and the Table of Contents are intentionally excluded. The Revision Page is kept.

## Diagrams

The example diagrams from the template are provided in two forms:
- `images/` — PNG reference exports (faithful to the original template).
- `diagrams/` — editable Draw.io XML re-creations of each UML diagram.

These are **example** diagrams from the template (online shopping / order system, from uml-diagrams.org and Satzinger/Arlow examples). They illustrate the expected diagram type for each section. Replace them with your own Knowledge Mapping diagrams when writing the actual SD.

The UTM logo and the test case template (a spreadsheet form, not a diagram) are kept as reference images only — no Draw.io versions.
