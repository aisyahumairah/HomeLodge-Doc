# System Documentation (SD) — HomeLodge Booking Homestay System

This directory contains the complete System Documentation for the **HomeLodge Booking Homestay System**, produced by applying the guidelines in `../` (the parent `system-design/` directory) to the HomeLodge project.

The SD combines three standards:

- **SRS** — Software Requirements Specification (Chapters 1 and 2)
- **SDD** — Software Design Description (Chapters 3, 4, 5, 6)
- **STD** — Software Test Documentation (Chapter 8 + Appendix A)
