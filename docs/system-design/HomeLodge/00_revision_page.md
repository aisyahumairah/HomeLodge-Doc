# Revision Page — HomeLodge Booking Homestay System

---

## 1. Overview

This is version 1.0 of the System Documentation (SD) for **HomeLodge**, a web-based homestay booking management system. This version covers the complete initial release of the SD, comprising all three constituent documents:

- **SRS (Software Requirements Specification)** — Chapters 1 and 2, covering the introduction, external interface requirements, and all functional system features across 13 modules (Authentication, Homestay Management, Booking, Payment, Notification, Chat, User Management, Role & Permission, System Settings, Audit Logs, QR Code Door Access, Reporting & Analytics, and Guest Feedback).
- **SDD (Software Design Description)** — Chapters 3 through 6, covering the system architectural design, detailed component descriptions, data design, and interface design.
- **STD (Software Test Documentation)** — Chapter 8 and Appendix A, covering test cases and the traceability matrix.

This version establishes the baseline documentation that all subsequent development, design, and testing activities will reference.
