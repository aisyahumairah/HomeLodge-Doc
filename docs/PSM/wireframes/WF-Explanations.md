# Wireframe Explanations

### 01-Authentication

**WF-AUTH-01: Register Account**
Figure 4.1 displays the user interface for the register account page. This page will be displayed after the user clicks on the "Sign Up" button from the landing page. It allows new users to create an account by entering their personal details and credentials.

**WF-AUTH-02: Login**
Figure 4.2 displays the user interface for the login page. This page will be displayed after the user clicks on the "Login" button. It allows existing users to authenticate and access their dashboard by entering their registered email and password.

**WF-AUTH-03: Logout**
Figure 4.3 displays the user interface or prompt for the logout action. This is triggered after the user clicks on the "Logout" option from the navigation menu or profile dropdown, ensuring their session is securely terminated.

**WF-AUTH-04: Forgot Password**
Figure 4.4 displays the user interface for the forgot password page. This page will be displayed after the user clicks on the "Forgot Password?" link on the login page. It allows users to request a password reset link to be sent to their registered email address.

**WF-AUTH-05: View Update Profile**
Figure 4.5 displays the user interface for the profile management page. This page will be displayed after the user clicks on their profile icon and selects "My Profile". It enables users to view and update their personal information, contact details, and preferences.

**WF-AUTH-06: Force Change Password**
Figure 4.6 displays the user interface for the force change password page. This page will be displayed immediately after a user logs in with a temporary password or when a system policy mandates a mandatory password update.

### 02-Homestay Management

**WF-HS-01: Browse Homestay Units**
Figure 4.7 displays the user interface for browsing homestay units. This page will be displayed after the user navigates to the "Homestays" section from the main menu. It presents a catalog of available units with filters to narrow down the choices.

**WF-HS-02: View Unit Details & Availability**
Figure 4.8 displays the user interface for homestay unit details and availability. This page will be displayed after the user clicks on a specific unit from the browse list. It provides comprehensive information about the unit, amenities, and a calendar showing available dates.

**WF-HS-03: Create Homestay Unit**
Figure 4.9 displays the user interface for creating a new homestay unit. This page will be displayed after a host or admin clicks on the "Add New Unit" button in their dashboard. It includes a form to upload images, set pricing, and describe the unit's features.

**WF-HS-04: Edit Homestay Unit**
Figure 4.10 displays the user interface for editing an existing homestay unit. This page will be displayed after the host clicks on the "Edit" button for a specific unit in their management list, allowing them to update the unit's information and availability.

**WF-HS-05: Deactivate Delete Unit**
Figure 4.11 displays the user interface prompt for deactivating or deleting a homestay unit. This prompt will be displayed after the host selects the "Deactivate" or "Delete" action, requiring confirmation to prevent accidental removal of the listing.

**WF-HS-06: View All Units List**
Figure 4.12 displays the user interface for the comprehensive list of all homestay units. This page will be displayed after the admin or host navigates to the "Manage Units" section. It shows a tabular or grid view of all units with their current statuses and quick action buttons.

### 03-Booking

**WF-BK-01: View Availability & Select Dates**
Figure 4.13 displays the user interface for viewing availability and selecting dates. This page will be displayed after the user clicks on "Check Availability" within a unit's detail page, allowing them to choose their desired check-in and check-out dates.

**WF-BK-02: Submit Booking**
Figure 4.14 displays the user interface for submitting a booking request. This page will be displayed after the user selects their dates and clicks "Proceed to Book". It summarizes the booking details, calculates the total cost, and requires the user to confirm their reservation.

**WF-BK-03: View Bookings**
Figure 4.15 displays the user interface for the user's booking list. This page will be displayed after the user navigates to "My Bookings" from the dashboard. It lists all upcoming, past, and canceled reservations associated with their account.

**WF-BK-04: View Booking Details**
Figure 4.16 displays the user interface for the booking details page. This page will be displayed after the user clicks on a specific booking entry. It shows comprehensive information about the reservation, including check-in instructions and payment status.

**WF-BK-05: Cancel Booking**
Figure 4.17 displays the user interface for canceling a booking. This page will be displayed after the user clicks on the "Cancel Booking" option within the booking details. It outlines the cancellation policy and asks for confirmation before processing the request.

**WF-BK-06: Manage Booking Admin**
Figure 4.18 displays the user interface for managing bookings from an admin perspective. This page will be displayed after an administrator navigates to the "Manage Bookings" dashboard, allowing them to oversee all reservations, approve requests, and handle disputes.

### 04-Payment

**WF-PAY-01: Make Payment**
Figure 4.19 displays the user interface for making a payment. This page will be displayed after the user confirms their booking and proceeds to checkout. It presents various payment methods and processes the transaction securely.

**WF-PAY-02: View Payment & Billing Records**
Figure 4.20 displays the user interface for viewing payment and billing records. This page will be displayed after the user clicks on "Billing History" in their profile. It provides a log of all past transactions, invoices, and payment statuses.

**WF-PAY-03: Regenerate Bill Receipt**
Figure 4.21 displays the user interface for regenerating a bill or receipt. This page will be displayed after the user clicks the "Download Receipt" action next to a specific transaction, allowing them to obtain a printable copy for their records.

### 05-Notification

**WF-NOTIF-01: Receive System Notification**
Figure 4.22 displays the user interface for receiving system notifications. This interface will be displayed as a dropdown or dedicated page after the user clicks on the "Notifications" bell icon. It lists recent alerts, messages, and updates related to their account or bookings.

**WF-NOTIF-02: Google Calendar Integration**
Figure 4.23 displays the user interface for Google Calendar integration. This page will be displayed after the user selects "Sync with Calendar" in their booking details or settings, enabling them to automatically add their reservations to their personal Google Calendar.

### 06-Chat

**WF-CHAT-01: Send Receive Messages**
Figure 4.24 displays the user interface for sending and receiving messages. This page will be displayed after the user clicks the "Message Host" or "Chat" button. It provides a real-time messaging window for communication between guests and hosts or support staff.

**WF-CHAT-02: View Chat History**
Figure 4.25 displays the user interface for viewing chat history. This page will be displayed when the user navigates to their "Inbox" or "Messages" section. It shows a list of past conversations, allowing the user to resume or review previous chats.

### 07-User Access Management

**WF-USR-01-02-03: Manage Users**
Figure 4.26 displays the user interface for managing users. This page will be displayed after the admin clicks on "User Management" in the admin dashboard. It provides tools to search, view, edit, or deactivate user accounts across the system.

**WF-USR-04-05: Manage Roles & Permissions**
Figure 4.27 displays the user interface for managing roles and permissions. This page will be displayed after the admin navigates to "Roles Settings". It allows administrators to define custom roles and assign specific system permissions to different user groups.

### 08-System Settings

**WF-SET-01: Configure System Settings**
Figure 4.28 displays the user interface for configuring system settings. This page will be displayed after the system administrator clicks on "System Configuration". It contains global settings such as site name, contact information, and operational parameters.

**WF-SET-02: Manage Default Policies**
Figure 4.29 displays the user interface for managing default policies. This page will be displayed after the admin selects "Policies" in the settings menu. It enables the creation and modification of standard terms, conditions, and cancellation policies applied across the platform.

### 09-Audit Logs

**WF-AUDIT-01: View & Filter Audit Trail**
Figure 4.30 displays the user interface for viewing and filtering the audit trail. This page will be displayed after an authorized admin clicks on "Audit Logs". It presents a secure log of system activities, filterable by date, user, and action type for security and compliance tracking.

### 10-QR Code Access

**WF-QR-01: Receive And Use QR**
Figure 4.31 displays the user interface for receiving and using a QR code. This page will be displayed after a booking is confirmed and paid for. It provides the user with a scannable QR code for keyless entry into their booked homestay unit.

**WF-QR-02: Housekeeping Cycle**
Figure 4.32 displays the user interface for the housekeeping cycle. This page will be displayed after the cleaning staff logs into their portal. It shows their assigned units and allows them to update the cleaning status using QR code scans or manual entry.

**WF-QR-03-04: Booking Extension**
Figure 4.33 displays the user interface for a booking extension request. This page will be displayed after the guest clicks on "Extend Stay" from their active booking details, allowing them to request additional days and generating an updated QR code upon approval.

### 11-Reporting & Analytics

**WF-RPT-01-02-03: Reporting Analytics**
Figure 4.34 displays the user interface for reporting and analytics. This page will be displayed after the management user clicks on the "Reports" dashboard. It provides visual charts and data summaries regarding occupancy rates, revenue, and system usage.

### 12-Guest Feedback

**WF-FB-01-02: Guest Feedback**
Figure 4.35 displays the user interface for submitting guest feedback. This page will be displayed after the user clicks on the "Leave a Review" link sent post-checkout. It allows guests to rate their stay and provide written comments about their experience.

**WF-FB-03: Manage Feedback Admin**
Figure 4.36 displays the user interface for managing feedback from an admin perspective. This page will be displayed after the admin navigates to "Reviews Management". It allows staff to read, moderate, and respond to guest reviews before they are published.

**WF-FB-04: Display Average Rating**
Figure 4.37 displays the user interface for displaying average ratings. This component will be displayed on the homestay unit's detail page or search results, aggregating all approved feedback to show the overall rating score to potential guests.
